# Backplates das arenas

Artes originais geradas para o projeto Lazer Beasts em 13 de agosto de 2026:

- `lazer_coliseum_backplate.png`: coliseu tecnológico principal.
- `obsidian_forge_backplate.png`: forja vulcânica para duelos com Fogo/Terra.
- `sky_temple_backplate.png`: templo celeste para duelos com Vento/Água.

Uso interno no estádio 3D da batalha. As imagens não contêm personagens,
texto, logos ou recursos de outra franquia. O horizonte é estático; piso,
faixas, luzes e combatentes são renderizados separadamente pelo Godot.
